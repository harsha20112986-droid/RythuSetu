# Data Layer

This directory is reserved for curated, versioned data used by RythuSetu.

Examples:

- Government scheme metadata
- Eligibility rules
- District / village reference data
- Crop reference data
- Climate-risk thresholds and methodology

Do not store personal farmer records or secrets in this directory.

For each externally sourced dataset, keep provenance such as source, URL, verified date, effective date, and version where applicable.
